## ВВЕДЕНИЕ

### Актуальность проблемы паводков в Кыргызстане

Кыргызская Республика, расположенная в горной зоне Центральной Азии, подвергается значительному воздействию опасных природных явлений, среди которых паводки и наводнения занимают одно из ведущих мест. Более 90% территории страны составляют горы Тянь-Шаня и Памиро-Алая, что обуславливает высокую подверженность паводковым процессам.

По данным Министерства чрезвычайных ситуаций Кыргызской Республики, ежегодно регистрируется от 50 до 100 случаев паводков и селевых потоков. Экономический ущерб от наводнений исчисляется миллионами долларов США. Так, в 2024 году селевые потоки в Ошской области унесли жизни 15 человек и нанесли ущерб в размере 5 миллионов долларов США.

**Основные причины паводков в Кыргызстане:**
- Интенсивные атмосферные осадки (весенне-летний период)
- Таяние снежного покрова и ледников
- Прорыв горных ледниковых озер
- Антропогенные факторы (вырубка лесов, нарушение естественного стока)

В условиях глобального изменения климата проблема прогнозирования паводков приобретает критическую актуальность. Повышение среднегодовой температуры приводит к интенсификации таяния ледников (площадь ледников Кыргызстана сократилась на 20% за последние 50 лет), изменению режима осадков и увеличению частоты экстремальных гидрометеорологических явлений.

### 1.1 Гидрологические процессы формирования паводков

#### 1.1.1 Определение и классификация паводков

**Паводок** - фаза водного режима реки, характеризующаяся интенсивным (обычно кратковременным) увеличением расхода воды и уровня, вызванная дождями или интенсивным таянием снега.

**Классификация паводков по происхождению:**

| Тип паводка | Характеристика | Период |
|-------------|----------------|--------|
| Дождевой | Формируется от интенсивных осадков | Весна-лето |
| Талый (половодье) | Связан с таянием снега | Весна |
| Ледниковый | Обусловлен таянием ледников | Лето |
| Смешанный | Комбинация факторов | Весна-лето |
| Прорывной | Прорыв ледниковых озер | Лето |

**Классификация по интенсивности:**

| Категория | Превышение нормы | Последствия |
|-----------|------------------|-------------|
| Низкий | < 150% | Минимальный ущерб |
| Умеренный | 150-200% | Затопление пойм |
| Высокий | 200-300% | Значительный ущерб |
| Критический | > 300% | Разрушения, жертвы |

#### 1.1.3 Уравнение водного баланса

Основное уравнение водного баланса водосбора:

$$P = Q + ET + \Delta S$$

где:
- $P$ - осадки (мм)
- $Q$ - сток (поверхностный + подземный)
- $ET$ - эвапотранспирация
- $\Delta S$ - изменение запасов воды в бассейне

### 1.2 Метод SCS-CN для расчета стока

#### 1.2.1 Теоретические основы метода

Метод **SCS-CN** (Soil Conservation Service Curve Number) разработан Службой охраны почв США и является одним из наиболее распространенных методов расчета поверхностного стока.

**Основное уравнение метода:**

$$Q = \frac{(P - I_a)^2}{P - I_a + S}, \quad при \; P > I_a$$

$$Q = 0, \quad при \; P \leq I_a$$

где:
- $Q$ - сток (мм)
- $P$ - осадки (мм)
- $I_a$ - начальные абстракции (мм)
- $S$ - максимальное потенциальное удержание (мм)

**Начальные абстракции:**

$$I_a = \lambda \cdot S$$

где $\lambda$ - коэффициент начальных абстракций (стандартное значение 0.2).

**Максимальное удержание:**

$$S = \frac{25400}{CN} - 254$$

#### 1.2.2 Реализация в системе

Метод SCS-CN реализован в модуле `src/models/scs_cn.py`. Основная функция расчета (`scs_cn.py:113-135`):

```python
def calculate_runoff(
    self,
    precipitation: Union[float, np.ndarray],
    cn: Union[float, np.ndarray]
) -> Union[float, np.ndarray]:
    """
    Расчет поверхностного стока по методу SCS-CN.

    Args:
        precipitation: Осадки (мм)
        cn: Номер кривой стока

    Returns:
        Сток (мм)
    """
    # Максимальное удержание почвой
    S = self._calculate_retention(cn)

    # Начальные абстракции
    Ia = self.lambda_coeff * S

    # Расчет стока
    runoff = np.where(
        precipitation > Ia,
        (precipitation - Ia) ** 2 / (precipitation - Ia + S),
        0
    )

    return runoff
```

### 1.3 Моделирование таяния снега (degree-day method)

#### 1.3.1 Метод температурного индекса

Для горных районов Кыргызстана таяние снега и ледников является одним из основных источников паводков. В системе реализован метод температурного индекса (degree-day method) в модуле `src/models/snowmelt.py`.

**Основное уравнение:**

$$M = DDF \cdot (T - T_{base}), \quad при \; T > T_{base}$$

$$M = 0, \quad при \; T \leq T_{base}$$

где:
- $M$ - интенсивность таяния (мм/день)
- $DDF$ - коэффициент таяния (мм/°C/день)
- $T$ - температура воздуха (°C)
- $T_{base}$ - пороговая температура (обычно 0°C)

**Типичные значения коэффициента таяния** (`snowmelt.py:32-34`):

```python
DEFAULT_DEGREE_DAY_FACTOR = 4.5  # мм/°C/день для снега
GLACIER_DEGREE_DAY_FACTOR = 7.5  # мм/°C/день для льда
```

#### 1.3.2 Реализация модели таяния

Функция расчета таяния (`snowmelt.py:79-105`):

```python
def degree_day_melt(
    self,
    temperature: float,
    degree_day_factor: float = None,
    dt_hours: float = 24
) -> float:
    """
    Расчет таяния методом температурного индекса.

    M = DDF * (T - T_base) * dt
    """
    if degree_day_factor is None:
        degree_day_factor = self.DEFAULT_DEGREE_DAY_FACTOR

    if temperature <= self.MELTING_POINT:
        return 0

    # Расчет таяния
    melt = degree_day_factor * (temperature - self.MELTING_POINT) * (dt_hours / 24)

    return max(0, melt)
```

#### 1.3.3 Динамика снежного покрова

Модель отслеживает состояние снежного покрова через класс `SnowpackState` (`snowmelt.py:15-23`):

```python
@dataclass
class SnowpackState:

    snow_depth: float             # Глубина снега (см)
    density: float                # Плотность (кг/м³)

```

**Уравнение баланса снежного покрова:**

$$\frac{dSWE}{dt} = P_s - M - E$$

где:
- $SWE$ - водный эквивалент снега
- $P_s$ - твердые осадки
- $M$ - таяние
- $E$ - испарение/сублимация

#### 1.3.4 Сезонный паттерн таяния

Для регионов Кыргызстана характерно различное распределение таяния в зависимости от высоты (`snowmelt.py:248-289`):

**Высокогорье (> 3000 м):**
- Пик таяния: июнь-июль (30% + 25%)
- Позднее начало таяния (май)

**Среднегорье (2000-3000 м):**
- Пик таяния: апрель-май (25% + 30%)
- Активное таяние с марта

**Низкогорье (< 2000 м):**
- Пик таяния: март-апрель (20% + 35%)
- Раннее начало таяния

### 1.4 Машинное обучение в гидрологии

#### 1.4.1 Применение ML методов

Машинное обучение в гидрологическом моделировании применяется для:

1. **Прогнозирования расхода воды** на основе метеорологических данных
2. **Классификации паводковых рисков** по множеству факторов
3. **Выявления аномалий** в гидрологических данных
4. **Оптимизации параметров** физически-обоснованных моделей

#### 1.4.2 Гибридный подход

В разработанной системе применяется гибридный подход:
- **Физически-обоснованные модели** (SCS-CN, degree-day) для расчета основных процессов
- **Статистические методы** для оценки параметров и валидации
- **Сценарный анализ** для оценки рисков при различных условиях

Оценка уровня риска паводка реализована в методе `_assess_flood_risk` (`flood_model.py:212-255`):

```python
def _assess_flood_risk(
    self,
    precipitation: float,
    discharge: float,
    soil_moisture: float
) -> FloodRiskLevel:
    """
    Оценка уровня риска паводка на основе нескольких критериев.
    """
    # Множитель для насыщенной почвы
    moisture_factor = 1 + soil_moisture

    # Критерии по осадкам
    if precipitation >= self.thresholds.PRECIPITATION_EXTREME * moisture_factor:
        precip_risk = 4
    elif precipitation >= self.thresholds.PRECIPITATION_HIGH * moisture_factor:
        precip_risk = 3
    # ...

    # Критерии по расходу
    threshold = self.params.flood_discharge_threshold
    if discharge >= threshold * 3:
        discharge_risk = 4
    # ...

    # Комбинированная оценка
    max_risk = max(precip_risk, discharge_risk)

    if max_risk >= 4:
        return FloodRiskLevel.CRITICAL
    elif max_risk >= 3:
        return FloodRiskLevel.HIGH
    elif max_risk >= 2:
        return FloodRiskLevel.MODERATE
    else:
        return FloodRiskLevel.LOW
```

```python
    snowfall_mm = precipitation_mm
    rainfall_mm = 0

    snowfall_mm = 0
    rainfall_mm = precipitation_mm
else:
    # Переходная зона (0-2°C)
```

```python
        self.params.degree_day_factor *
```

```python
                duration_hours=len(period),
                peak_discharge_m3s=period['discharge_m3s'].max(),
```

#### 2.3.6 Расчет времени концентрации

Класс `RunoffCalculator` (`src/models/runoff.py`) реализует расчеты гидрографа стока.

**Формула Кирпича** (`runoff.py:37-73`):

$$T_c = 0.0078 \cdot L^{0.77} \cdot S^{-0.385}$$

```python
def calculate_time_of_concentration(
    self,
    watershed: WatershedParameters,
    method: str = "kirpich"
) -> float:
    """
    Расчет времени концентрации водосбора.
    """
    L = watershed.main_channel_length_km
    S = watershed.average_slope

    if method == "kirpich":
        L_ft = L * 3280.84  # км в футы
        tc_min = 0.0078 * (L_ft ** 0.77) * (S ** (-0.385))
        tc_hours = tc_min / 60

    return max(tc_hours, 0.1)  # Минимум 6 минут
```

#### 2.3.2 Единичный гидрограф SCS

Построение безразмерного единичного гидрографа (`runoff.py:85-125`):

```python
def scs_unit_hydrograph(
    self,
    watershed: WatershedParameters,
    duration: float = 1.0,
    time_step: float = 0.1
) -> Tuple[np.ndarray, np.ndarray]:
    """
    Построение единичного гидрографа SCS.
    """
    tc = self.calculate_time_of_concentration(watershed)
    lag = self.calculate_lag_time(tc)  # L_ag = 0.6 * Tc

    # Время пика
    tp = duration / 2 + lag

    # Пиковый расход (м³/с на 1 мм избыточных осадков)
    A = watershed.area_km2
    qp = 2.08 * A / tp

    # Генерация гидрографа
    for i, t in enumerate(time):
        t_ratio = t / tp
        if t <= tp:
            # Фаза подъема
            discharge[i] = qp * (t_ratio ** 2.5)
        else:
            # Фаза спада
            discharge[i] = qp * np.exp(-1.5 * (t_ratio - 1))

    return time, discharge
```

#### 2.3.3 Маршрутизация методом Маскингама

Метод Маскингама для трансформации гидрографа (`runoff.py:152-180`):

```python
def muskingum_routing(
    self,
    inflow: np.ndarray,
    K: float,
    X: float,
    dt: float
) -> np.ndarray:
    """
    Маршрутизация стока методом Маскингама.

    Коэффициенты:
    C0 = (dt - 2*K*X) / (2*K*(1-X) + dt)
    C1 = (dt + 2*K*X) / (2*K*(1-X) + dt)
    C2 = (2*K*(1-X) - dt) / (2*K*(1-X) + dt)
    """
    denominator = 2 * K * (1 - X) + dt
    C0 = (dt - 2 * K * X) / denominator
    C1 = (dt + 2 * K * X) / denominator
    C2 = (2 * K * (1 - X) - dt) / denominator

    outflow = np.zeros_like(inflow)
    outflow[0] = inflow[0]

    for i in range(1, len(inflow)):
        outflow[i] = C0 * inflow[i] + C1 * inflow[i-1] + C2 * outflow[i-1]
        outflow[i] = max(0, outflow[i])

    return outflow
```

```python
def _get_seasonal_factor(self, day_of_year: int) -> float:
    """
    Сезонный коэффициент для Кыргызстана:
    - Весенний максимум (март-май)
    - Летние ливни (июнь-август)
    - Сухая осень-зима
    """

    spring_peak = 100
    spring_factor = np.exp(-((day_of_year - spring_peak) ** 2) / 2000)

    # Летние осадки (июль)
    summer_peak = 200
    summer_factor = 0.7 * np.exp(-((day_of_year - summer_peak) ** 2) / 3000)

    # Базовый уровень
    base = 0.3

    return base + spring_factor + summer_factor
```

```python
    """
    Расчет направлений стока методом D8.

    Кодирование направлений:
    32  64  128
    16   X   1
     8   4   2
    """
    for i in range(1, rows - 1):
        for j in range(1, cols - 1):
            max_drop = 0
            direction = 0

            for (di, dj, code), dist in zip(offsets, distances):
                ni, nj = i + di, j + dj
                drop = (self.dem[i, j] - self.dem[ni, nj]) / (dist * cell_size)
```

**Топографический индекс влажности (TWI)** (`terrain.py:227-245`):

$$TWI = \ln\left(\frac{a}{\tan(\beta)}\right)$$

где $a$ - площадь водосбора на единицу ширины, $\beta$ - уклон.

```python
def calculate_twi(self) -> np.ndarray:
    """
    Расчет топографического индекса влажности.
    """
    specific_catchment = self.flow_accumulation * self.cell_size
    slope_rad = np.radians(np.maximum(self.slope, 0.01))
    twi = np.log(specific_catchment / np.tan(slope_rad))
    return twi
```

### Приложение А. Инструкция по установке и запуску

**Требования к системе:**
- Python 3.10 или выше
- 4 ГБ оперативной памяти
- 500 МБ свободного места на диске

**Установка:**

```bash
# Клонирование репозитория
git clone <repository_url>
cd diploma

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt
```

**Запуск моделирования:**

```bash
# Базовый запуск
python main.py --region chui --scenario normal --days 365

# Параметры:
#   --region, -r    : chui, issyk_kul, naryn, osh, jalal_abad, talas, batken
#   --scenario, -s  : dry, normal, wet, extreme
#   --days, -d      : число дней (по умолчанию 365)
#   --output, -o    : директория для результатов
#   --verbose, -v   : подробный вывод
#   --no-plots      : не создавать графики
```

**Использование Python API:**

```python
from src.models.flood_model import FloodModel
from src.utils.helpers import generate_sample_data

# Генерация данных
data = generate_sample_data(region='chui', days=365, scenario='normal')

# Создание модели
model = FloodModel(region='chui')
model.initialize_state(data['timestamp'].iloc[0])

# Запуск моделирования
results = model.run_simulation(data)

# Выявление событий
events = model.detect_flood_events(results)
print(f"Обнаружено событий: {len(events)}")

# Статистика
stats = model.calculate_flood_statistics()
```

### Приложение Б. Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **AMC** | Antecedent Moisture Condition - условия предшествующего увлажнения почвы |
| **CN** | Curve Number - номер кривой стока, безразмерный параметр метода SCS |
| **DDF** | Degree-Day Factor - коэффициент таяния (мм/°C/день) |
| **SWE** | Snow Water Equivalent - водный эквивалент снега (мм) |
| **TWI** | Topographic Wetness Index - топографический индекс влажности |
| **Водосбор** | Территория, с которой вода стекает в данную реку |
| **Гидрограф** | График изменения расхода воды во времени |
| **Инфильтрация** | Просачивание воды в почву |
| **Паводок** | Кратковременное повышение уровня воды в реке |
| **Расход воды** | Объем воды через сечение за единицу времени (м³/с) |
